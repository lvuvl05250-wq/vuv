# 项目演示

本仓库收录两个项目的交互演示，均可直接在浏览器中打开。

| 项目 | 简介 | 在线演示 |
| --- | --- | --- |
| 同频 · 招聘 Agent | 面向业务负责人和 HR 的招聘协作原型，串联岗位需求、候选人推荐、业务反馈与招聘状态管理。 | [打开招聘演示](https://lvuvl05250-wq.github.io/vuv/) |
| 微活 | 陪伴式生活记录工具，从一件小行动开始，记录饮食、心情和每日手账。 | [打开微活演示](https://lvuvl05250-wq.github.io/vuv/weihuo/) |

## 同频 · 招聘 Agent

支持切换业务与 HR 角色，体验创建岗位需求、HR 接收、添加候选人、编辑推荐内容、确认提交和处理反馈等主要流程。演示使用示例数据，不连接真实招聘系统。

## 微活

网页演示基于原生微信小程序制作，沿用原有插画与 137 条行动，支持行动搜索与分类、计时和完成、自定义行动、手动餐食记录、今日感受、日记归档及陪伴伙伴切换。

记录保存在当前浏览器，可导出为 JSON。微信登录、云同步和 AI 照片识别未接入网页演示。

- [下载原生微信小程序源码](https://lvuvl05250-wq.github.io/vuv/weihuo-source.zip)
- [查看网页演示源码](./weihuo/)

## 运行与部署

两个网页演示均为静态 HTML、CSS 和 JavaScript，无需安装依赖。下载仓库后，通过静态服务器打开根目录即可访问招聘演示，访问 `/weihuo/` 可打开微活。

GitHub Pages 发布来源为 `main` 分支的根目录 `/(root)`。
