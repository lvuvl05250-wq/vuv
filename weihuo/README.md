# 微活网页演示

入口：`/vuv/weihuo/`。打开 `index.html` 或通过静态服务器运行，不需要安装依赖。

基于原生微信小程序制作，沿用原始插画与 137 条行动。支持行动搜索、分类、计时、完成和自定义行动，手动餐食记录与编辑，今日感受、日记归档、昵称与伙伴切换、JSON 导出。数据只保存在当前浏览器 localStorage；建议定期导出。

微信登录、云备份、AI 识别及微信平台权限未接入此网页演示。源码下载在仓库根目录 `weihuo-source.zip`，包含原生客户端、云函数和测试，排除了本地环境文件、私有开发配置、依赖目录和本机预览日志。

GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main → /(root)。招聘演示保留在仓库根目录。
